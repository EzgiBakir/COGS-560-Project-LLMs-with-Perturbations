# COGS-560-Project-LLMs-with-Perturbations
Research Project of Ezgi Bakır (student number 2740504) for the Course Cogs560-LLMs for Reasoning and Cognition 

This repository contains the dataset, prompts, model outputs, and code
for the term project "EVALUATING THE ROBUSTNESS OF GEMMA MODELS ON PERTURBED REASONING QUESTIONS: A COMPARATIVE STUDY".

## Contents
- `Dataset_updated` — the 100-question dataset (English + Turkish, with solutions and notes)
- `python_pipeline_codes` —(local Ollama for Gemma 2 9B and Gemma 4 E4B; Google API for Gemma 4 31B)
- `Questions for 8-shot prompt` — the Python pipelines 
- `Results of gemma2_9b` raw answers from Gemma2_9b
- `Results of gemma4_31b` raw answers from Gemma4_31b
- `Results of gemma4_e4b` raw answers from Gemma4_e4b
- `Project Report-Ezgi Bakır-2740504.pdf` — the full project report

## Models
- Gemma 2 9B (Ollama)
- Gemma 4 E4B (Ollama)
- Gemma 4 31B (Google API)
